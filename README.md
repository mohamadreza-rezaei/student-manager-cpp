# student-manager-cpp

In-memory student management system written in C++ for a university course, plus a few related practice scripts.

## Contents

- `student.cpp` — main student manager
- `Student Manager/` — project folder
- Extra practice files: `barareh_2.py`, `bulldozer.py`, `graph.py`, `soduku.py`

## Tech

- C++ (core app)
- Some Python utilities included in the repo

## Build / run

Open the project in your IDE (CLion / Visual Studio / g++) and compile `student.cpp`, or build the contents of `Student Manager/`.

```bash
g++ -o student student.cpp
./student
```
